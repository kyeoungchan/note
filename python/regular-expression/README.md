## ✅ 메타 문자
> [!TIP]
> `\`(백슬래쉬)를 붙이고 다음 나오는 문자는 한 글자와 매칭된다.

| 메타 문자  |설명| 예시                                   |
|--------|---|--------------------------------------|
| ^      |이 패턴으로 시작해야 함| ^abc: abc로 시작해야 함 (abcd, abc12 등)    |
| $      |이 패턴으로 종료돼야 함| xyz$: xyz로 종료돼야 함 (123xyz, strxyz 등) |
| [문자들]  |문자들 중에 하나이어야 함. <br> 가능한 문자들의 집합을 정의함.| [Pp]ython: "Python" 혹은 "python"      |
| [^문자들] |[문자들]의 반대로 피해야할 문자들의 집합을 정의함.| [^aeiou]: 소문자 모음이 아닌 문자들             |
| \|     |두 패턴 중 하나이어야 함.| a\|b: a 또는 b이어야 함.                   |
|?|앞 패턴이 없거나 하나이어야 함. <br> (Optional 패턴을 정의할 때 사용)| \d?: 숫자가 하나 있거나 없어야 함.               |
|+|앞 패턴이 하나 이상이어야 함.| \d+: 숫자가 하나 이상이어야 함.                 |
|*|앞 패턴이 0개 이상이어야 함.|
|패턴{n}|앞 패턴이 n번 반복해서 나타나는 경우|\d{3}: 숫자가 3개 있어야 함.|
|패턴{n,m}|앞 패턴이 최소 n번, 최대 m번 반복해서 나타나는 경우 <br> (n 또는 m은 생략 가능)|\d{3,5}: 숫자가 3, 4, 혹은 5개 있어야 함.|
|\d|숫자 0~9|\d\d\d: 0~9범위의 숫자가 3개를 의미(123, 000등)|
|\w|문자를 의미 <br> (영어대소문자, 숫자 0-9, 언더바 '_'를 포함)|\w\w\w: 문자 3개를 의미(xyz, ABC 등).|
|\s|공백을 의미하는데, ['\t', '\n', '\r', '\f']와 동일|\s\s: 화이트 스페이스 문자 2개를 의미(\r\n, \t\t)|
|.|뉴라인(\n)을 제외한 모든 문자를 의미|.{3}: 문자 3개(F15, 0x0 등)|

<br>

> [!CAUTION]
> `[]`: 대괄호  
> 대괄호 사이에 원하는 문자를 여러 개 넣으면, 문자열이 넣은 문자 중 하나와 일치하면 매칭이 된다.  
> 대괄호 안에서는 `.`, `*`, `+`는 하나의 문자가 된다.

<br>

> [!CAUTION]
> `^`: 캐릿  
> 대괄호 앞에 `^`이 들어가면 대괄호의 내용과 반대되는 것을 반환한다.  
> 예를 들어 `^[0-9]`면 숫자가 아닌 것을 반환한다.

## ✅ 정규식 그룹

---

> [!NOTE]
> `()` 괄호로 그룹을 묶을 수 있다.  
> 그룹 안에서 `|`를 사용하거나 그룹 뒤에 수량자를 붙이는 패턴이 자주 사용된다.
> 예를 들어, `(\d)-(\d-\d)`으로 묶었다면 group(1)은 `\d`, group(2)는 `\d-\d`가 된다.  
> `(my|your)name`은 `myname`, `yourname`과 매치된다.  
> `(slow|quick){2}`는 `slowslow`, `quickquick`, `slowquick`, `quickslow`와 매치된다.


<br>

### 🚀 그룹의 재사용
> [!NOTE]
> 패턴에서 그룹을 지정하면 만들어진 순서대로 1번부터 번호를 사용하면 패턴 내에서 재사용할 수 있다.  
> `(test)data₩₩1`은 `testdatatest`와 매치된다.

<br>

### 🚀 그룹 사용 예시

> [!TIP]
> `dog`, `dogog`, `dogogog`...처럼 `d` 문자 뒤에 `og`라는 문자열이 1개 이상 반복되는 문자열을 매치하고 싶을 때 다음과 같이 사용 가능하다.  
> `d(og)+`

<br>

```python
import re

text = "dogogogogogog"

p1 = "dog"
p2 = "d(og)+"

m1 = re.search(p1, text)
m2 = re.search(p2. text)

print("m1 결과: ", m1.group()) # dog
print("m2 결과: ", m2.group()) # dogogogogogog 
```

<br>

### 🚀 비캡쳐
> [!NOTE]
> 그룹은 사용하되 캡처하지 않겠다고 명시하여 문자열을 매칭하는 것이 비캡쳐링 그룹이다.  
> `(?:)`로 사용한다.  
> - 캡처링 그룹: (패턴) -> 매칭 시 match.group(1), match.group(2) 등으로 결과가 저장됨
> - 비캡쳐링 그룹: (?:패턴) -> 매칭은 이루어지지만 결과 메모리에 저장되지 않음.

```python
import re

text = '123-456-7890'

# 첫 번째 그룹은 비캡처(?:), 두 번째와 세 번째는 캡처()
pattern = r'(?:\d+)-(\d+)-(\d+)'
match = re.search(pattern, text)

if match:
    print('전체 매치:', match.group(0))  # 123-456-7890
    print('첫 번째 그룹(비캡처):', match.groups())  # ('456', '7890') -> 첫 번째 123은 그룹 결과에 포함되지 않음
    print('두 번째 그룹:', match.group(1))      # 456
    print('세 번째 그룹:', match.group(2))      # 7890
```

## ✅ 그외 정규식

---

> [!NOTE]
> - `re.match`('패턴', '검사하려는 문자열')
>   - 문자열의 처음부터 패턴 일치 여부 확인
>   - `Match` 객체 또는 `None`을 반환한다.
> - `re.search`
>   - 처음부터가 아니라 중간에 있어도 상관 없음.
>   - `Match` 객체 또는 `None`을 반환한다.
> - `re.findall`: 문자열 중 패턴과 일치되는 모든 부분 찾기
>   - 문자열 리스트를 반환한다.

<br>

> [!IMPORTANT]
> `Match` 객체에서 아래와 같은 여러 정보를 꺼낼 수 있다.
> ```python
> import re
> 
> m = re.search(r'\d+', 'abc123def')
> 
> m.group() # '123' → 매칭된 문자열
> m.start() # 3 → 시작 인덱스
> m.end()   # 6 → 끝 인덱스
> m.span()  # (3, 6)  → (시작, 끝) 튜플
> ```
